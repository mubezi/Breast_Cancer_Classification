# Breast_Cancer_Classification

## Overview
This project implements multiple machine learning classifiers to predict breast cancer diagnosis (malignant or benign) using the Wisconsin Breast Cancer dataset. The project compares the performance of various classification algorithms and includes comprehensive visualization of results.
Dataset Description
The breast cancer dataset is loaded from scikit-learn and includes:

**569 samples**
30 features computed from images of breast mass samples
Binary classification: Malignant (0) or Benign (1)

**Features Include:**

Mean radius, texture, perimeter, area
Mean smoothness, compactness, concavity
Mean concave points, symmetry, fractal dimension
And their standard error and "worst" values

**Models Implemented**

K-Nearest Neighbors (KNN)
Logistic Regression
Decision Tree
Random Forest
Support Vector Machine (SVM)
